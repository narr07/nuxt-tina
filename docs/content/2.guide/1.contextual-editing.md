# Contextual Editing

Contextual editing lets an editor see their changes on the live page immediately, without hitting save or waiting for a rebuild.

## Communication architecture

Tina Admin and Nuxt talk to each other over a secure cross-window messaging protocol:

```
+-------------------------------------------------------------+
| Tina Admin Window (/admin)                                  |
|   +-------------------------------------------------------+ |
|   | Form Fields (Sidebar / Overlay)                       | |
|   +---------------------------+---------------------------+ |
|                               | postMessage                 |
|                               v                             |
|   +-------------------------------------------------------+ |
|   | <iframe> (Nuxt page: http://localhost:3000/blog/x)    | |
|   |   nuxt-tina runtime bridge                            | |
|   |   -> listens for 'tinacms:form:change'                | |
|   |   -> updates the Vue ref in real time                 | |
|   +-------------------------------------------------------+ |
+-------------------------------------------------------------+
```

## Event lifecycle

1. **Client ready**: once the Nuxt page finishes loading inside the iframe, the bridge sends a `tinacms:client:ready` event with the current URL to Tina Admin.
2. **Form sync**: Tina Admin detects the matching form for that URL and shows the editing sidebar.
3. **Reactive patching**: every keystroke or value change in the Tina form is sent as a payload to the iframe, picked up by the `useTina()` composable, and patched into the DOM.
