A wrapper component that makes visual-editing status available to the whole child component tree, and shows an optional preview indicator.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showIndicator` | `boolean` | `false` | Shows a floating "Tina Visual Preview" badge in the bottom-right corner when the page is loaded inside the Tina Admin iframe. |

## Slots

- **default**: the app content to wrap.

## Usage example

```vue
<template>
  <TinaProvider :show-indicator="true">
    <NuxtLayout>
      <NuxtPage />
    </NuxtLayout>
  </TinaProvider>
</template>
```
