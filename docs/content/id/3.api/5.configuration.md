---
title: "Konfigurasi Module"
description: "Referensi opsi config tina di nuxt.config.ts."
---

Semua opsi module diset di bawah key `tina`:

```ts
export default defineNuxtConfig({
  modules: ['nuxt-tina'],
  tina: {
    clientId: process.env.NUXT_TINA_CLIENT_ID,
    token: process.env.NUXT_TINA_TOKEN,
    branch: 'main',
    visualEditing: true,
    media: {
      publicFolder: 'public',
      mediaRoot: 'uploads',
      provider: 'tina',
    },
    enabled: true,
  },
})
```

Semua opsinya opsional — module-nya balik ke default yang wajar, termasuk baca credentials dari environment. Lihat [Instalasi & Konfigurasi](/getting-started/installation) buat daftar env var-nya.

## Opsi

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `clientId` | `string` | env var `NUXT_TINA_CLIENT_ID` \| `TINA_CLIENT_ID` | Client ID Tina Cloud kamu. |
| `token` | `string` | env var `NUXT_TINA_TOKEN` \| `TINA_TOKEN` | Token read-only Tina Cloud (cuma disimpan di server-side). |
| `branch` | `string` | env var `NUXT_TINA_BRANCH` \| `HEAD`, kalau nggak ada `'main'` | Branch Git yang jadi target query content. |
| `tinaPath` | `string` | `'tina'` | Lokasi folder config Tina, relatif ke root project. |
| `visualEditing` | `boolean` | `true` | Ngaktifin plugin bridge postMessage iframe di sisi client. |
| `media.publicFolder` | `string` | `'public'` | Folder tempat public web asset berada. |
| `media.mediaRoot` | `string` | `'uploads'` | Subfolder tempat gambar yang diupload disimpan. |
| `media.provider` | `'tina' \| 'cloudinary'` | `'tina'` | Backend media store-nya. `'cloudinary'` ngedaftarin route `/api/cloudinary/**` — lihat [Media & Cloudinary](/guide/media). |
| `enabled` | `boolean` | `true` | Matiin module-nya sepenuhnya kalau `false`. |
