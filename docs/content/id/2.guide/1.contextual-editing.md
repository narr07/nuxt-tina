title: 'Contextual Editing'
description: 'Cara kerja alur komunikasi postMessage dan live preview.'
---

Contextual editing bikin editor bisa lihat perubahannya langsung di halaman live, tanpa perlu save atau nunggu rebuild.

## Arsitektur komunikasi

Tina Admin dan Nuxt saling ngobrol lewat protokol messaging antar-window yang aman:

```
+-------------------------------------------------------------+
| Tina Admin Window (/admin)                                  |
|   +-------------------------------------------------------+ |
|   | Form Fields (Sidebar / Overlay)                       | |
|   +---------------------------+---------------------------+ |
|                               | postMessage                 |
|                               v                             |
|   +-------------------------------------------------------+ |
|   | <iframe> (Halaman Nuxt: http://localhost:3000/blog/x) | |
|   |   nuxt-tina runtime bridge                            | |
|   |   -> dengar event 'tinacms:form:change'               | |
|   |   -> update ref Vue secara real time                  | |
|   +-------------------------------------------------------+ |
+-------------------------------------------------------------+
```

## Siklus event

1. **Client ready**: begitu halaman Nuxt selesai dimuat di dalam iframe, bridge kirim event `tinacms:client:ready` beserta URL saat itu ke Tina Admin.
2. **Form sync**: Tina Admin deteksi form yang cocok buat URL itu dan nampilin sidebar editing.
3. **Reactive patching**: setiap ketikan atau perubahan value di form Tina dikirim sebagai payload ke iframe, ditangkap sama composable `useTina()`, dan di-patch ke DOM.
