## Setup Tina Cloud

1. Bikin project di [app.tina.io](https://app.tina.io) dan konek ke repo GitHub kamu.
2. Copy **Client ID** dan **Read-only Token** dari dashboard project.
3. Simpan sebagai environment variable:

```env
NUXT_TINA_CLIENT_ID=<client-id-kamu>
NUXT_TINA_TOKEN=<token-kamu>
```

4. Build admin production-nya (bukan mode dev lokal):

```bash
npx tinacms build
```

`tinacms dev` **selalu** nampilin banner "You are in local mode" apapun isi `clientId`-nya: itu bukan bug, itu emang perilaku CLI-nya. Login Tina Cloud yang beneran cuma muncul di build production (`tinacms build` tanpa `--local`, terus dideploy atau dijalankan lewat `nuxi build && nuxi preview`).

## Dua mode editing

`nuxt-tina` nggak "gantiin" editor bawaan Tina. Dua mode ini jalan independen:

| Mode | URL | Butuh bridge kita? |
| --- | --- | --- |
| **CMS dasar** (stabil) | `/admin#/collections/<name>/edit/<file>` | Nggak: form-nya baca/tulis langsung ke local data layer |
| **Visual/contextual** (eksperimental) | `/admin#/~/<page-path>` | Iya: pakai `useTina()` + `data-tina-field` |

Kalau visual editing kerasa belum stabil di project kamu, mode CMS dasar tetap jalan penuh sebagai fallback.
